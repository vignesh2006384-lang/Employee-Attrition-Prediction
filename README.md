# Employee Attrition Prediction

## Project Overview
This project predicts employee attrition using Machine Learning techniques and helps identify factors influencing employee turnover.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Seaborn

## Dataset
IBM HR Employee Attrition Dataset

## Project Workflow
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Machine Learning Model Building
5. Model Evaluation

## Outcome
Developed a predictive model to identify employees likely to leave the organization and analyzed key factors affecting attrition.
